- **Teardown no longer waits on a callback; joins happen at `collect()` (#2751).** Removing a
  connection used to wait for the link's callbacks while holding the transport vertex's
  control lock, and a callback inside a control-plane operation needs that lock. So a removal
  that arrived on the removed link, or on another link, could wait for good. The waits now run
  after the lock is released. A teardown made on a thread that runs link callbacks (a link's
  own thread, or the node wait module's driver) waits for nothing: it stops the link, and the
  link's destructor, run at the graph's next `collect()` outside every callback, joins its
  threads. A self-healing link's liveness publish now resolves its connection first, so a
  publish after the removal writes nothing. New `tr::net::on_callback_thread()` reports
  whether the calling thread runs link callbacks.
