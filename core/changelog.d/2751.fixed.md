- **Teardown no longer waits on a callback; joins happen at `collect()` (#2751).** Removing a
  connection used to wait for the link's callbacks while holding the transport vertex's
  control lock, and a callback inside a control-plane operation needs that lock. The waits now
  run after the lock is released. Lifetime rules: a teardown on a thread that runs link
  callbacks (a link's own thread, or the node wait module's driver) is deferred, and only
  shuts down; it doesn't close. A link's descriptors stay owned and open until its destructor
  runs. Destructors always join, and run off callback threads. `graph_t::collect()` called on
  a callback thread returns at once and frees nothing; links removed from a callback are
  joined and freed at the next `collect()` or at graph destruction. A self-healing link's
  liveness publish now resolves its connection first, so a publish after the removal writes
  nothing. New `tr::net::on_callback_thread()` reports whether the calling thread runs link
  callbacks. An application liveness subscriber must not remove its own connection from
  inside the liveness callback.
