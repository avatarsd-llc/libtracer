- **A link can name why it last dropped an outbound frame (#2788).** `tr::net::drop_cause_t`
  (`NONE`, `OVERSIZE`, `LINK_DOWN`, `SHED`, `TRANSPORT_ERROR`) is one byte a `drop_tally_t` keeps
  when its `drop_classes_t` sets `dropped_tx_cause`: the link counts each outbound drop with
  `count_dropped_tx(n, cause)`, and `transport_drop_stats_t::dropped_tx_cause` reports the last
  one. A tally that does not set it pays nothing and reports no cause. The router publishes the
  cause as a fourth noun of `:stats.link.<child>`, `dropped_tx_cause`, only for a link that keeps
  one (RFC-0010 Amendment 6). The ESP-IDF WebSocket client link is the first to keep it.
