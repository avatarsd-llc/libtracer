- **A subscriber edge's admission charges are one record, given back by one release
  (#2814).** The admission step takes the session's ADMIT, the listener count, the link hold
  and the departure index entry in that order, and from the ADMIT on every refusal gives the
  whole record back through `graph_t::release_admission`, the same release a replace's
  displaced edge, a clear and a retirement use. A refused index entry is now answered as the
  slot verb's REFUSED (`BACKPRESSURE`, as before). The record stores nothing: the release names
  the session from the edge's cold half through the link-name seam, so a refused admission's
  `RELEASE` follows the contract `graph_hooks_t::link_name` already states for a clear or a
  replace. A local edge has no session: `link_index_t::index_vertex` and the session-event
  step answer the empty one inline, so a local subscribe makes no call for either, and a local
  `:subscribers[]` edge whose write carried a link is handed no session at its door, so it is
  still never offered nor indexed. Not breaking: no public signature changes. The esp32c6
  libtracer component shrinks by 56 B in `full_node` (180,824 to 180,768) and in
  `transport_footprint` (183,469 to 183,413); static RAM and every transport row are unchanged.
