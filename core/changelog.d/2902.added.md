- **A per-link bound on parked waiters (#2902).** `config_t::kMaxAwaitsPerLink` (default 8)
  caps how many deferred remote AWAITs one link may hold at once. One more on that link is
  answered `BACKPRESSURE` and counted in the new `fwd_router_t::await_refusals()`, which also
  counts an AWAIT whose waiter block the link plane refused. Other links still park. The bound
  costs no byte per link.
