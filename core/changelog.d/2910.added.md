- **`transport_t::set_session_down_notifier` (#2910).** A flat link that carries several
  sessions (a TCP or WS listener with `peer_named` false) reports each session's departure with
  the session's handle, from the thread that saw it and with no transport lock held. The default
  ignores the call, so a single-session link, a datagram link and a peer-named link are unchanged.
  `bus_link_t::store_peer_down` is the protected store behind it and behind
  `set_peer_down_notifier`.
